# Screenshots

These images are documentation snapshots of the shipped surfaces — not design
mockups, and not runtime assets. The README and the live `/demo` tour both use
the same four.

The screenshots use synthetic local records rather than household data.

## Catalogue

![Desktop catalogue](screenshots/catalogue-desktop.png)

The catalogue lists five finite encounters with filters, a local watchlist,
research summaries, and owner-controlled restart of earlier encounters. Small
decorative cats appear in the header, the empty watchlist, and saved-observation
receipts.

## Safety gate

![Safety gate](screenshots/safety-gate.png)

Playback stays unavailable until the viewer selects a screen context and confirms
device stability, protected cables, an open exit, and continuous supervision.

## Tablet scene

![Tablet scene](screenshots/tablet-scene.png)

The paused player keeps owner controls outside the scene, starts muted, exposes a
scene-motion setting, and provides resume and stop. Optional scene sound is
synthesized locally with Web Audio and starts muted.

## Mobile catalogue

![Mobile catalogue](screenshots/catalogue-mobile.png)

The primary catalogue works at a 412 × 915 viewport without a separate mobile app.
